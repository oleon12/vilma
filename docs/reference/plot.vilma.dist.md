# Plot VILMA Distribution Rasters

Provides a quick visualization of a `vilma.dist` object, including:

- **Species Richness Raster** – Displays species richness per cell with
  numerical values.

- **Abundance Raster** – Displays species abundance per cell with
  numerical values.

## Usage

``` r
# S3 method for class 'vilma.dist'
plot(x, ...)
```

## Arguments

- x:

  An object of class `vilma.dist`, typically generated by
  `points.to.raster()`.

- ...:

  Additional arguments passed to plotting functions (currently not
  used).

## Value

Produces raster plots for richness and abundance. No values are
returned.

## Details

This function is intended for quick inspection of VILMA distribution
objects. It plots both species richness and abundance rasters, labeling
each cell with its value.
