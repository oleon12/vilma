# Example points for demonstration

Loads an example points (CSV format) included in the package.

## Usage

``` r
example_dist()
```

## Value

An object of class `data.frame` or `matrix`.

## Examples

``` r
dist <- example_dist()
head(dist)
#>    Sp       Lon       Lat
#> 1 Sp1 -65.69729  -2.38575
#> 2 Sp1 -62.12766  -5.46646
#> 3 Sp1 -68.46476  -6.62311
#> 4 Sp1 -47.72880 -10.90319
#> 5 Sp1 -59.84149 -11.68981
#> 6 Sp1 -60.04203   2.66623
```
