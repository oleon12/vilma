# Plot Rasters from a VILMA PD Object

Provides a quick visualization of raster layers from `vilma.pd` objects.
For each raster stored in the object, this function displays the grid
values on a map, with numerical values shown per cell.

## Usage

``` r
# S3 method for class 'vilma.pd'
plot(x, ...)
```

## Arguments

- x:

  An object of class `vilma.pd`, typically the output of a PD
  calculation.

- ...:

  Additional arguments passed to plotting functions (currently unused).

## Value

Produces raster plots of the layers contained in the `vilma.pd` object.
Invisibly returns the input object.

## Details

This function is designed for quick inspection of phylogenetic diversity
or abundance rasters generated by VILMA. Each raster layer is plotted
sequentially, and cell values are displayed directly on the map. Users
can directly access raster data for more advanced plotting if needed.
