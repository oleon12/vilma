# Print Summary of a VILMA Null Model

Displays a textual summary of a `vilma.null` object. Depending on the
null model method, it prints either global PD statistics or
cell-specific SES and p-values.

## Usage

``` r
# S3 method for class 'vilma.null'
print(x, ...)
```

## Arguments

- x:

  An object of class `vilma.null`, typically generated by a VILMA null
  model function.

- ...:

  Additional arguments (currently unused).

## Value

Invisibly returns the input object. Primary purpose is printing a
summary to the console.

## Details

For objects with `Method = "global"`, the function reports observed PD,
mean and SD of null PD, standardized effect size (SES), and whether the
p-value is `< 0.05`. For `Method = "cell"`, it prints summary statistics
of PD, null PD, SES per cell, and the number of cells with significant
p-values.
